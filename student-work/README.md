# Prace laboratoryjne WiRR

Katalog w **KIA-students/wirr** zawiera wzory dokumentowania ćwiczeń, a nie rejestr ocen ani publiczną bazę tożsamości studentów.

## Zawartość

- [Przykładowy raport Lab 01](examples/lab01-report-example.md): fikcyjne pomiary FPS, wyliczenie mediany i wniosku
- [Przykładowy raport Lab 02](examples/lab02-report-example.md): fikcyjne próby interakcji, błędy, mediana i interpretacja

**Uwaga:** przykłady nie są autentycznymi pracami studentów i nie potwierdzają ukończenia laboratoriów.

## Jak przygotować swoją pracę?

1. Otwórz projekt Unity z pakietem WiRR Course Toolkit.
2. W menu **WiRR → Student → Profil i grupa** uzupełnij własny profil.
3. Wybierz **WiRR → Raporty → Formularz raportu laboratoryjnego**, odpowiednio Lab 01 lub Lab 02.
4. Uzupełniaj pomiary na bieżąco. Zachowaj dane surowe, warunki pomiaru i wniosek.
5. Uruchom **Sprawdź kompletność raportu**, następnie **Eksportuj raport lokalnie**.
6. Plik JSON znajduje się w `Library/WiRRReports/exports`. Prześlij go **kanałem wskazanym przez prowadzącego**, a nie przez automatyczny publiczny PR.

Nie publikuj w ogólnodostępnym repozytorium numerów indeksów, nazwisk, pełnych raportów identyfikujących studentów ani indywidualnych wyników SSQ. Gdy prowadzący udostępni kontrolowany mechanizm przekazywania prac, instrukcja zostanie odpowiednio uzupełniona.

**Pełne szablony** znajdują się w odpowiednich instrukcjach PDF Lab 01 i Lab 02 jako załączniki, a przykłady poniżej pokazują tylko jeden ukończony punkt kontrolny 3.0.
