
# Kotwica to nie gwarancja stałości

Materiały pilotażowe do instrukcji 2.0.0-draft.2.

Prowadzący przygotowuje projekt przez `WiRR → Nowe instrukcje → Przygotuj osiem scen`. Student otwiera gotową scenę i uruchamia Play. Nie instaluje SDK ani nie pisze kodu.

Scena: `Lab03_AnchorGallery.unity`; źródło danych: **SIM_AR**. Polecenia i progi są dostępne bez sieci w panelu sceny. Profil solo/para jest wspólny dla dwóch laboratoriów.

Po pracy eksportuj dwa wyniki bloku. Zapis lokalny nie oznacza wysłania ani uzyskania oceny. Pełne podłączenie nowych checkpointów i odbiór na stanowiskach pozostają otwarte.

Materiały kursu: https://github.com/KIA-students/wirr

Szczegółowa instrukcja krok po kroku (język polski): [laboratorium 03](https://github.com/MatPomGit/prz/blob/main/courses/wirtualna-i-rozszerzona-rzeczywistosc/laboratories/lab-03/content.md).
