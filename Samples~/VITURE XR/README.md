# VITURE XR: przykład WiRR

Ten sample uzupełnia Laboratorium 01, 02 lub 07 o demonstrację stereoskopii na okularach VITURE XR.

## Szybki start

1. Podłącz okulary VITURE do komputera.
2. W Unity otwórz scenę testową.
3. Wybierz `WiRR → VITURE XR → Utwórz przykład Full SBS 3840x1080`.
4. Uruchom Play Mode.
5. Ustaw okno/budowanie na 3840×1080.
6. Włącz 3D Mode w okularach.
7. Porównaj wynik z trybem 2D.
8. Następnie uruchom Immersive 3D VITURE na zwykłej treści 2D i porównaj charakter głębi.

Dokumentacja: `Documentation~/Reference/VITURE_XR.md`.
