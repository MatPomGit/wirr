
# Bliźniak cyfrowy powinien wiedzieć, kiedy nie wie

Instrukcja dla studentów: [Laboratorium 06, krok po kroku](https://github.com/MatPomGit/prz/blob/main/courses/wirtualna-i-rozszerzona-rzeczywistosc/laboratories/lab-06/content.md). Eksport bloku jest lokalny; adapter importu w PR #116 obejmuje laboratoria 01–08. Po zakończeniu Play użyj `WiRR → Nowe instrukcje → Przenieś wyniki do formularza raportu`, wybierz laboratorium 06 i zweryfikuj tryb `ROS_REPLAY`; nie wpisuj fikcyjnego RTT. Raport wysyła `Zapisz raport lokalnie (bez logowania)`, a dopiero potwierdzenie serwera oznacza jego przyjęcie.

Materiały pilotażowe do instrukcji 2.0.0-draft.2.

Prowadzący przygotowuje projekt przez `WiRR → Nowe instrukcje → Przygotuj osiem scen`. Student otwiera gotową scenę i uruchamia Play. Nie instaluje SDK ani nie pisze kodu.

Scena: `Lab06_DigitalTwin.unity`; źródło danych: **ROS_REPLAY**. Polecenia i progi są dostępne bez sieci w panelu sceny. Profil solo/para jest wspólny dla dwóch laboratoriów.

Po pracy wyłącz `Play`, wybierz `WiRR → Nowe instrukcje → Przenieś wyniki do formularza raportu`, wskaż sesję bloku 03 i zaimportuj kolejno laboratoria 05 i 06. Zweryfikuj dwa potwierdzenia odbioru przez serwer. Lokalny eksport nie oznacza wysłania ani oceny. [Pełna instrukcja i karta do druku](https://github.com/MatPomGit/prz/blob/main/courses/wirtualna-i-rozszerzona-rzeczywistosc/laboratories/lab-06/content.md). Pełne podłączenie nowych checkpointów i odbiór na stanowiskach pozostają otwarte.

Materiały kursu: https://github.com/KIA-students/wirr
