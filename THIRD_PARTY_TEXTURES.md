# Third-party texture assets

The optional material-learning prefabs use a curated subset of texture assets whose identifiers correspond to ambientCG materials.

Included asset families:

- AcousticFoam003
- Concrete032
- DiamondPlate005D
- Fabric023
- Fabric066
- Metal004
- Metal044A
- PaintedWood007A
- Sign002
- Grass001
- WoodFloor034
- WoodFloor040

ambientCG publishes its assets under the Creative Commons CC0 1.0 Universal license.

Source and license information:
https://ambientcg.com/

These texture files are kept separate from the MIT-licensed WiRR source code in `Textures/Surfaces/`.
