Jeden start projektu na blok i dwa niezależne wyniki przesyłane z Unity. Na końcu sprawdź potwierdzenia przyjęcia obu raportów. System automatycznie przekazuje je do KIA-students/wirr; e-mail służy wyłącznie awarii. Instrukcje mają trzy działania, a progi 3.0–5.0 rozwijają to samo doświadczenie. Możesz zakończyć na osiągniętym etapie; nie musisz uzyskać 5.0, aby rozpocząć drugie laboratorium.
